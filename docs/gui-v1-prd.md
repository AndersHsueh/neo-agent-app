# neo GUI v1 —— 产品需求（PRD）

> 状态：**M0–M3 已实现（前端 + dummy-serv）** · 2026-10-28
> 上游：`gui-prd.md`（形态定案 v2）、`neo-prototype-2/`（视觉验收基准）、`gui-build-plan.md`
> 下游：`gui-v1-architecture.md` / `gui-v1-protocol.md` / `gui-v1-design-system.md`

## 1. 一句话

给 `neo` CLI 一个桌面工作台：**多会话并行、状态看得见、每写一次文件都要人点头**；
并且**按登录用户隔离与计费**——同一台机器多个人用，也不糊涂账。

## 2. 用户与角色

| 角色 | 说明 |
|---|---|
| **Operator（用户）** | 登录者。发起任务、审批写盘、回答问题、看用量。v1 里同一个账号可在多个标签页观察同一会话 |
| **Agent（NEO）** | 每个会话一个 agent。界面上的正文、思维链、工具、统计都由它的 `SessionEvent` 驱动 |
| **Hub（无 UI）** | 会话进程的托管者与事件源。v1 里由 dummy-serv 扮演，真后端另做 |

## 3. 核心对象

- **构造（Session）**：一次工作上下文。有标题、档位、状态（空闲/运行中/等你决定/停滞/已断开）、归属用户。
- **轮次（Turn）**：一次用户输入到 `stats` 收口。UI 用分隔行标号。
- **块（Block）**：时间线上的最小单位，共 11 种（turn/user/assistant/reasoning/tool/approval/question/tierline/stats/banner/error）。
- **审批（Approval）**：写盘前的强制闸门，带 diff 与超时。
- **提问（Question）**：agent 需要人做选择时的单选卡。
- **用量（Usage）**：每轮 token 与成本，归属**会话所有者**。

## 5. 关键流程

1. **首次登录**：登录 → WS 认证 → 拉会话列表 → 自动 attach 第一个会话 → 显示快照。
2. **一轮完整流程**：输入 → `turn.send`（乐观上屏 + `clientId`）→ 思维链 → 工具 → 提问 → 回答 → 审批 → 允许/拒绝分支 → 升档 → 统计。
3. **拒绝不是中止**：拒绝后 agent 改走只读方案并继续给结果；用量照记。
4. **断线恢复**：socket 断开 → 自动重连 → `attach{lastSeq}` → 快照补齐；挂起的提问/审批仍在；本地未落盘消息按 `clientId` 去重。
5. **多人同机**：登录 A 只看 A 的会话与用量；退出后本地不留 A 的 token 与缓存；切到 B 重新拉取。
6. **语言切换**：中/英即时切换（UI + 内容；后续轮次由后端按会话语言生成）。

## 7. 验收（与实现对齐）

- 登录后 3 个会话（owner 隔离）；tom 登录只有 1 个。
- 一轮流程在 40s 内走完：提问卡 → 审批 → 允许 → `stats` 出现，署名变 `MR. ANDERSSON`，档位停在深思。
- 审批弹窗内连按 6 次 Tab 焦点不逃出；Esc 关闭后 `#app.inert === false`。
- dummy 注入 `drop-ws` 时：出现「连接中断」横幅、自动恢复、用户消息数不重复、挂起提问仍在。
- 英文界面除语言按钮外无中文字符。
- `tsc` / `biome` / `vitest` / `playwright` 全绿（证据见 `docs/evidence/`）。

## 8. 明确的边界

- **无真后端**：dummy-serv 只按协议发事件，不接模型、不执行工具、不 spawn 进程。
- **无 Tauri 壳**：窗口/托盘/单实例/自动更新在 M4。
- **代码片段中的中文注释不随语言切换**：代码是内容，不是 UI 文案；后续真 hub 由模型按用户语言生成。
- **provider 密钥永不进入前端**：设置页只见掩码；`settings.patch` 不支持改密钥。

## 9. 开放问题

- 跨用户派活（A 给 B 的会话发消息）时计费归属：默认记**接收方会话所有者**，UI 标注派发人（尚未实现）。
- provider 密钥是用户级还是机器级：当前按用户级建模；owner 下发共享 key 的策略未定。
- 登录最终形态（本地账号 / OIDC / 团队 SSO）：v1 只实现本地账号，数据模型与 `AuthState` 可替换。
